# Skills del negocio Drop

Carpeta para Skills de Claude Code (`.claude/skills/<nombre>/SKILL.md`): procedimientos concretos y repetibles que Vega Duarte (CEO) o los subagentes pueden invocar para una tarea puntual (a diferencia de un subagente, que es un especialista de área completo — ver [../agents/README.md](../agents/README.md)).

## Por qué está vacía

Todavía no hay tareas repetitivas identificadas con suficiente concreción como para convertirlas en skill sin inventar el flujo de trabajo. Se añaden aquí a medida que un subagente o el CEO detecten que una misma tarea se repite y conviene empaquetarla (ver también el criterio en [../agents/ceo.md](../agents/ceo.md): "si una tarea se repite ≥3 veces, evalúa convertirla en subagente o proceso").

## Candidatas previsibles (sin construir todavía)

- Responder un tipo de incidencia de atención al cliente recurrente.
- Evaluar un producto candidato con los criterios ya definidos en [../agents/busqueda-producto.md](../agents/busqueda-producto.md).
- Generar un reporte de rendimiento de campaña con los principios de [../agents/marketing.md](../agents/marketing.md).
